# FilterTube extension 3.6.2: release record

Prepared 2026-11-18 on `release/ext-3.6.2`, branched from `origin/master` at
`9dbd30a3`. This is the developer-facing record of every non-website commit on
`origin/master` since 2026-11-07 (166 commits, plus 6
merge commits). The user-facing summary is the 3.6.2 entry in
[CHANGELOG.md](../CHANGELOG.md).

## Version

- The extension goes from **3.5.0 to 3.6.2**. 3.6.0 and 3.6.1 were app-only
  releases (tag `v3.6.0` is the apps' GitHub release); the extension version
  follows the apps again from here.
- Bumped: `manifest.json`, `manifest.chrome.json`, `manifest.firefox.json`,
  `manifest.opera.json`, `package.json`, `package-lock.json` (both version
  fields), the two version labels in `html/tab-view.html` ("v3.6.2" and
  "Current version: v3.6.2"), their keys and values in all 38
  `data/ui_locales/*_static.json` catalogs, and the README source-version badge.
- Not changed on purpose: historical CHANGELOG and release-note entries, the
  3.5.0 app artifact names used as parser fixtures in
  `tests/runtime/public-release-surface-current-behavior.test.mjs`, and the
  "Builds before 3.5.0" comment in `build.js`.
- `build.js`: the README version-badge regex now also matches the
  `![Extension source version](…)` badge (it only matched `![Version](…)`, which
  the README no longer had), keeping the alt text.

## What's New (data/release_notes.json)

The shared notes already carried the apps' 3.6.2 entry, mirrored verbatim from
the app (`462f298b`, `d33a7764`, `7e860c80`, `8b539c8b`) and translated into 37
locales (`6c8af96e`). Because the list holds one entry per version, this release
keeps the app's headline, summary, banner line and ten highlights unchanged and
appends two extension highlights (Home, the hidden log, the support line, the
popup; then the extension fixes). Both are translated into all 37
`data/ui_locales/release_notes.<locale>.json` overlays, so each overlay still has
as many highlights as the English entry.

Known gap: the banner line ("…and a calmer viewer") and some highlights describe
app-only features (the viewer, tablets, TVs, app icon, DeArrow).

## Verification

Run on this branch with Node 22.17.1 (dependencies linked from the main
checkout's `node_modules`, because `npm ci` fails on a lockfile entry,
`async-3.2.8.tgz`, that the registry returns 404 for):

| Check | Result |
| --- | --- |
| `node build.js` (all browsers) | Pass. Chrome, Firefox and Opera zips at 3.6.2; README badges refreshed. |
| Manifests, package files, release notes and every `data/ui_locales/*.json` parse as JSON | Pass |
| `npm test` (smoke lane) | 1,987 tests, 15 failures, the same 15 that fail on `origin/master` |
| `npm run test:release` | 1,194 tests, 29 failures, all also failing on `origin/master` (which has 30; the release-notes schema test now passes) |
| `npm run audit:runtime` (every runtime test) | 8,026 tests, 1,275 failures, all also failing on `origin/master` (which has 1,277; the two release-version tests now pass) |
| `npm run check:ui-locales` | Exits 1, as on `origin/master` (Russian plural keys flagged as extra); no new findings |
| `npm run check:release-note-locales` | 3.6.2 complete in all 37 locales; 3.5.0 and 3.4.2 are still English only (pre-existing) |

Pre-existing failures are source pins (callable counts, line-number and
fingerprint registers) that drifted on `origin/master` before this branch.

Not checked: the extension in a real browser profile by hand (Chrome, Firefox,
Opera or Edge), a signed-in account on the video site, store package review,
and a native review of the new translations. The earlier parity passes ran
automated Chromium walkthroughs on the live site, signed out
(`docs/design/PARITY_PASS4.md`), and headless captures of the popup and options
page.
