## Implementation boundaries

`js/shared/view_count.js` is the shared parser. Dedicated total-view fields and explicitly labeled owner-scoped metadata are accepted; arbitrary titles, ages, likes, playlist totals and concurrent-viewer counts are not. Compact counts use conservative bounds rather than treating rounded text as exact. Optional views do not add a metadata request, a pending admission requirement, or persistent popularity metadata. Exact Player totals are retained only in the current video-keyed session metadata path.

Main/Kids control saves use their existing personal or managed-parent paths. Blank/invalid active inputs do not overwrite rules; switching the filter off retains its previous valid minimum. The actual UI-constructor and save tests cover both prefixes and managed-save denial. Existing engine explicit-allow precedence is retained. Archived livestream VODs can remain exempt when YouTube retains `isLiveContent`; this conservative coverage limit is not full archived-live support. The pre-existing difference between engine content-filter exceptions and direct-player content-filter decisions is documented by tests, not broadly changed in this task.

BlockTube compatibility uses pinned upstream [import logic](https://github.com/amitbl/blocktube/blob/d8a1bdba062ab603726b0ac3ea06c229d61fd710/src/ui/options.js#L219-L237) and [compiler logic](https://github.com/amitbl/blocktube/blob/d8a1bdba062ab603726b0ac3ea06c229d61fd710/src/scripts/background.js#L34-L77). The unmodified relevant upstream functions are executed in tests, including editor join/split and re-save. Unicode literals, exact-word matching, regex flags, slashes/newlines, IDs and a large Unicode list are covered. Unsupported semantics cannot silently become a complete-export claim. Preview/export recheck actor, parent ownership, PIN verifier and reviewed data; stale review or authority changes produce no download. BlockTube's importer also clears its options-page password; the review explicitly warns users to back it up and configure its password again. No FilterTube PIN, key or device trust is exported.

See [the compatibility guide](../BLOCKTUBE_EXPORT_COMPATIBILITY_2026-10-17.md) for precise mappings.
